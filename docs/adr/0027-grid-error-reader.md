# ADR-0027: セルエラーを局所オーバーレイで読み、参照と再試行を分ける

> English: [0027-grid-error-reader.en.md](0027-grid-error-reader.en.md)

- 状態: Accepted
- 日付: 2026-11-04
- 関連: [Issue #495](https://github.com/tyaro/banto/issues/495) / [spec §4.5](../ui-framework-spec.md#45-セル編集) / conventions §8・§9・§13

## コンテキスト

従来のエラーはセル直下の absolute / nowrap で、右端・下端で切れる。
320px のブラウザで幅278pxの表に幅約2757pxのメッセージが入り、表の scrollWidth も増えることを確認した。
折返しだけでは下端の欠けが残る。通常フローの領域で表を縮めると、仮想化 window から
編集中の行を外し得る。極長文にはスクロールとキーボードでの全文参照が必要になる。

## 決定

常設 `.banto-grid-frame` の中で scrollport とエラー領域を兄弟にする。
領域だけを absolute で重ね、表の寸法・行配置・editor の DOM / session を保つ。
可視範囲へ幅を収め、上下を切り替え、高さを制限して領域内をスクロール可能にする。
位置更新は本文を作り直さず、表示やスクロールだけでフォーカスを動かさない。

本文は従来の一意な ID と `role="alert"` を保ち、入力の `aria-describedby` が参照する。
外側は名前付き・フォーカス可能な非modalの region とし、本文とキー操作ヒントを説明に持つ。

- Enter 失敗時は入力を保持する。既存エラー中の Tab / Shift+Tab は読む操作にし、再送信しない。
  入力変更後も Enter を明示的な再試行にする。
- エラーなしの Tab は確定し、失敗時だけ同じ session・フォーカス所有権・接続を確かめて領域へ移す。
- 領域の Shift+Tab / Escape は入力へ戻るだけとし、保存・取消しない。
  矢印・PageUp/Down・Home/End・forward Tab は標準動作に任せる。
- 現在の入力から同じ編集の領域への移動では blur 保存を抑止する。
  遅延した失敗で外部操作先や後続編集のフォーカスを奪わない。
- IME／処理済みキーの所有権を維持し、メッセージは省略可能な bundle で注入する。

## 代替案

| 案                              | 評価                                                       |
| ------------------------------- | ---------------------------------------------------------- |
| セル直下で折返しだけ追加        | 下端の欠けと長文へのキーボード到達を解決しない             |
| 通常フローのエラー領域          | scrollport を縮め、仮想化中の editor を外し得る            |
| scrollport 内の sticky          | 含有 block・横スクロール・コンテンツ高との関係が複雑になる |
| body portal／汎用 floating 基盤 | 今回の局所的なエラー表示に範囲を広げすぎる                 |

## 帰結

通常の非編集画面と表のサイズは維持する。DOM の直下構造やエラー中の Tab に依存する利用側には
移行注意を出す。表の全幅を使うため他の行を一時的に覆うが、入力と本文の関連付け・明示再試行を保つ。
新規依存・package 間 import・外部コードや素材の取り込みは追加しない。
狭幅・文字200%・入れ子のスクロール・下端・仮想化・保存失敗とフォーカスの回帰を実ブラウザで検証する。
