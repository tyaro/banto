# レシピ: ログイン無しの小さなアプリ（チョイアプリ）として始める

作成日: 2026-09-01（choiapp-feedback-2026-09 §5 から切り出し。トラックB＝
アプリ作者向け）

担当者数人・単機能の小さなアプリでは、毎回のログインが一番のノイズになる。
Banto は **M11 ログイン不要モード**でこれに対応している: ログイン画面なしで
使い始めて、アプリが育ったら（複数人・ロール分離・LAN 配信が要るように
なったら）通常のログイン運用へ切り替えられる。

## ログイン無しで始める

1. テンプレートをコピー・リネームし、デスクトップアプリ（Tauri）として起動する。
2. 初回セットアップ画面で管理者アカウントを 1 つ作る（現状スキップ不可 —
   ここで決めたパスワードが、後でログイン運用へ戻すときの鍵になるので控えて
   おく）。
3. **設定 → セキュリティ → 認証を無効化** で「ログイン不要モード」を ON にし、
   起動時のロール（通常は `admin`）を選んで保存する。

以後はログイン画面なしで起動し、選んだロールの synthetic session として
動く。ユーザーメニュー/パスワード変更は自動的に隠れ、ヘッダに
「ログイン不要モード」のステータスチップが出る。

制約（いずれも仕様 M11 の意図的な護り）:

- **デスクトップ（Tauri）ウィンドウ限定。** LAN ブラウザ配信とは排他で、
  ログイン不要モード中は LAN アクセスを有効化できない（逆も同じ）。
- 端末を開ける人は誰でも操作できる。**完全に信頼できる端末でのみ**使うこと。
- 監査ログは synthetic session の actor で記録され続ける。

さらに手早くしたい場合は `pnpm scaffold --preset minimal` でオプション資産
（dock/charts/添付/帳票など）をまとめて外せる（README「オプション資産の削除」）。

## 育ったらログイン機能を足す

同じトグルを戻すだけでよい:

1. **設定 → セキュリティ → 認証を無効化** を OFF にして保存（この操作は
   ログイン不要モード中なら synthetic session のロールに関係なく実行できる —
   キオスク的に `viewer` で運用していても戻せる escape hatch）。
2. 次回起動からログイン画面が戻る。初回セットアップで作った管理者アカウントで
   ログインし、**設定 → アカウント**でパスワード変更、ユーザー管理画面で
   メンバーのアカウントを追加する（ロールの増やし方は
   [add-role.md](add-role.md)）。
3. 必要なら **設定 → サーバ・接続 → LANアクセス**を有効化して LAN 配信へ
   （README「LANアクセス」の注意書きを必ず読むこと）。

毎回のパスワード入力だけを省きたい（がアカウントは残したい）中間形態には
**自動ログイン**（設定 → アカウント → 自動ログイン。資格情報は OS キーリング
保存）もある。

## 既知の宿題

「初回セットアップ自体をスキップして最初からログイン無し」はまだできない
（管理者アカウント作成が必須）。デフォルト化の提案は
[docs/choiapp-feedback-2026-09.md §5](../choiapp-feedback-2026-09.md) に記録
されている。
